# Travel & Tourism Data Analysis Dashboard

## Project Overview

This project is an interactive Travel & Tourism Data Analysis Dashboard created using Microsoft Excel. The project analyzes tourism data to identify travel trends, tourist behavior, spending patterns, destination popularity, transport preferences, and hotel booking insights.

## Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Slicers
* KPI Cards
* Dashboard Design

## Key Features

* Interactive dashboard with slicers
* KPI summary cards
* Monthly travel trend analysis
* Destination-wise tourist analysis
* Budget and rating comparisons
* Gender distribution analysis
* Hotel booking insights
* Transport mode analysis

## Visualizations Used

* Bar Charts
* Column Charts
* Pie Charts
* Doughnut Charts
* Line Charts

## Project Outcome

This project demonstrates practical Excel skills in data visualization, dashboard creation, and business insight generation.
